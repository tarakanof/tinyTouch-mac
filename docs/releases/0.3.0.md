## Updates inside the app

tinyTouch now keeps itself up to date. It checks for a new version once a day and asks before installing it, or choose **Check for Updates…** in the app menu or on the About page. Turn automatic checks and background downloads on or off in **Application** settings.

Every update is signed and verified before it's installed, and the background helper moves to the new version on its own, so password entry keeps working.

This is the first version that can update itself: if you have 0.2.0, download this one from GitHub once.
